# Prompt 02 · 打磨 GitHub 页面 / 阅读体验

请先读 AGENTS.md 与 README.md。当前 `index.html` 是由 `scripts/build_site.py` 从精读 Markdown 生成的静态阅读页，样式在 `assets/style.css`。

任务：让它像一篇极简中文数字杂志，手机端和电脑端都非常好读。重点检查正文宽度、中文行高、字号、目录、时间戳链接样式、证据与编辑说明的层级、键盘访问和屏幕阅读器基本可用性。只用 HTML/CSS 和少量原生 JS（确有必要时），不要引入大型前端框架，也不要加追踪器和用户账号。

验收：本地可打开；长标题不溢出；375px 手机宽度没有横向滚动；正文可读且无花哨装饰；所有相对路径仍可通过 GitHub Pages 子路径访问。必须保留“转录对照但尚未完成听音核对”的提示。

不要改动访谈观点与时间戳。完成后运行测试，并列出修改文件与截图检查建议。
